Offline & Type-Safe

The Compiler sits upstream of your Deployer

Model-X Configuration (MXC) is a declarative, compile-time-validated platform configuration engine built on CUE. It decouples developer logical intent from actual cluster manifest orchestration.

Interactive Demo Quick Start & Docs

Our Core Axiom

"Application configuration will never be unified.
Deployment configuration must be."

Every application carries structurally unique requirements (GPUs, network sockets, sidecars). Instead of writing brittle string-replacement YAML templates, MXC defines uniform, validated constraints and compiles them down to target layouts.

Engine Architecture

Designed to provide robust mathematical safety, high-fidelity platform targets, and a dry-run local developer workflow.

🛡️

Type-Safe Validation

Standalone-Ready

The Mathematics of Validation

Unlike scripting engines, CUE compiles configurations using Order Theory and Lattices. Conflicting specifications collapse immediately into Bottom (⊥).

The Lattice Theory Concept

In CUE, schemas and concrete parameters occupy the same mathematically ordered space. The top element _ (Top ⊤) matches any value, while concrete values form leaves on the tree.

When two fields unify using the & operator, CUE computes the Greatest Lower Bound. If their specifications conflict (e.g. attempting to define a CPU limit as both an integer and a string), the operation collapses into Bottom (⊥), throwing a type-error instantly during compilation.

  • Top (⊤): Unconstrained field (written as _)
  • Unification (&): Merges constraints and parameters
  • Disjunction (|): Standard enums / Choice constraints
  • Bottom (⊥): Turned-T error representing structural conflicts
